# ISC Abu Dhabi - Landing Page Recreation

A premium, modern recreation of the Indian Social & Cultural Centre (ISC) Abu Dhabi website landing page. Built with HTML5, CSS3 (Custom Stylesheet), and Bootstrap 5.

## Features
- **Official Branding**: Features a sharp vector SVG logo of the Indian Social & Cultural Centre Abu Dhabi on a transparent background.
- **Modern UI/UX**: Includes standard color variables (Saffron, Navy Blue, Green) matching the official colors.
- **Glassmorphic Elements**: Floating header navigation and a sleek back-to-top button with circular scroll progress tracking.
- **Staggered Scroll-Reveal Animations**: Clean entrance animations on page load, combined with scroll-reveal staggered animations for sections and cards using a lightweight JavaScript Intersection Observer.
- **Interactive Micro-Animations**: Card hover translations, floating date badges, and a custom shine sweep animation over image wrappers.
- **Fully Responsive**: Scaled and tested across mobile, tablet, and wide desktop screen layouts.

## File Structure
- `isc2.html`: Main landing page structure.
- `isc2.css`: Global variables, typography, layouts, animations, and media queries.
- `assets/`: Image assets and the official vector SVG logo.
